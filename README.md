# 二号机，蹦蹦守门员

竖屏波次生存自动射击小游戏（Canvas 2D，无外部依赖）。

在线试玩：https://zilonghe.github.io/bengbeng/

`node test.js` 运行无头逻辑测试。

## v3：六章远征

- 6 章、60 关，每章独立构筑；第 5、10 关出现首领，整章通关解锁下一章。
- 荒野、锈铁、迷雾、冰封、熔火、暗夜各有配色、敌人增援和环境机制。章节重新计算难度，避免第 60 关沿用无尽模式的指数增长。
- 完成关卡和击败敌人获得金币；整章通关额外奖励 150，每日补给 120。空局退出不送金币。
- 招募 12 种开局卡，单次 120、十连 1080。普通 / 稀有 / 史诗概率 70% / 25% / 5%，十连至少稀有，最多 20 抽必出史诗。重复卡升级，未升级时返币。
- 携带一张开局卡进入战斗；每局一次免费重抽，重抽至少出现一张稀有卡。原有 37 种战斗强化（含 7 种进化）保留。
- 本地挑战榜分纯净与辅助成绩；携卡、重抽、复活都会计入辅助榜。存档包含金币、图鉴、章节和最近 100 局成绩。

这轮先打磨网页内容。未连接平台时不显示购买和广告复活入口；微信小游戏、真实广告、支付和全球榜留待后续接入。`?preview=1` 可验证广告完成 / 取消、一次复活和测试补给；界面始终标识测试，使用独立存档，没有真实广告或扣款。复活恢复 60% 生命并无敌 3 秒，一局最多一次。详细接入契约见 [INTEGRATION.md](INTEGRATION.md)。

### 本地运行

无需安装依赖。Node.js 18+ 用于测试；任意静态服务器均可运行游戏：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/`。数据保存在当前浏览器的 localStorage；旧版最佳生存天数只作为旧纪录保留，不折算成章节解锁。浏览器拒绝写入时，抽卡和奖励操作会失败并提示，不会先扣币。

### 验证

```sh
node campaign.test.js
node economy.test.js
node services.test.js
node ui.test.js
node test.js -q
node campaign-balance.js
```

前四项为确定性规则、经济、平台接口和控制器回归。`test.js` 保留原版随机策略模拟；`campaign-balance.js` 用固定种子分别跑裸装和史诗主炮，支持 `BALANCE_SEEDS=606,707,808` 与 `--json`。模拟的移动与选卡策略只读取当前战场和可选卡，未使用复活或重抽。自动模拟不代表真人趣味性或触屏体验验收；后几章仍有难度，需要试玩继续调整。
